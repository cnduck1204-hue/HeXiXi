# 核夕夕开发起点

目标：基于当前本地 rCore 建立独立的团队项目，可编译并启动到用户 Shell。
NoAxiom 作为内核、用户程序、测试、工具、文档职责分离的参考。

方案：保留 rCore 的 os、user、easy-fs、easy-fs-fuse 与 bootloader 路径，
避免仅为目录名称改动内部依赖和启动链路；当前不提前拆分公共库或引入子模块。
首版沿用现有 RISC-V64、Rust 和 QEMU 配置，不新增 LoongArch 支持。

执行与验证：

1. 复制 rCore 已跟踪的相关源码、许可证和构建配置，不复制 Git 历史、缓存或编译产物。
   核对来源版本和文件差异。
2. 添加统一构建运行入口、团队说明和核夕夕启动标识。
   核对脚本语法，实际完成 Docker 内编译。
3. 启动 QEMU，进入用户 Shell，执行 hello_world 并等待返回 Shell。
   由 tests/boot.py 检查启动标识和用户态输出。

范围：建立可继续开发的 rCore 衍生基线，不改写内存管理、调度或文件系统，
不宣称具备官方赛事测例兼容性。保留上游署名和 GPL-3.0 许可证。
